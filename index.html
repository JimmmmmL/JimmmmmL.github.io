Coherence-Aware Distributional Evaluation of Open-Ended Text Generation

Jinnuo Liu*, Junhao Zhu*, Weifeng Jiang, Haoming Liu, Hongyi Wen

arXiv preprint, 2026

We propose CHORD, a distributional metric for open-ended generation that accounts for global coherence. It catches coherence failures that perplexity, entropy and MAUVE miss, and its rankings closely match human judgments of sensibility and human-likeness.

NovelAPIBench: Diagnosing How A Code LLM Learns to Use Novel APIs

Jinnuo Liu, Yue Peng, Jinhan Niu, Hongyi Wen

arXiv preprint, 2026

We build a diagnostic benchmark that separates whether a code LLM can use API knowledge it is given from whether it has internalized that knowledge. Post-training with SFT or RAFT clearly improves the first, but leaves the second close to zero.

From Navigation to Refinement: Revealing the Two-Stage Nature of Flow-based Diffusion Models through Oracle Velocity

Haoming Liu, Jinnuo Liu, Yanhao Li, Liuyang Bai, Yunkai Ji, Yuanhe Guo, Shenji Wan, Hongyi Wen

CVPR 2026, Findings track

Using the closed-form oracle velocity of flow matching, we show that training has two stages: early navigation across data modes, which generalizes and forms global layout, and later refinement toward the nearest sample, which memorizes fine detail. This explains why timestep shifting, guidance intervals and latent-space choices work.

Early Learning Shapes Later Directions of Representation Change in Continual Learning

Yuantao Deng*, Jinnuo Liu*, Kaizhen Tan, Yuchen Liu

arXiv preprint, 2026

We track how representations change as a model learns tasks in sequence, and find that the directions set during early learning shape the directions in which representations change later.

ValueFlow: Measuring the Propagation of Value Perturbations in Multi-Agent LLM Systems

Jinnuo Liu, Chuke Liu, Hua Shen

arXiv preprint, 2026

We introduce a perturbation-based framework that measures how a shift in one agent's values spreads through a multi-agent system. Susceptibility varies sharply across values and depends strongly on how agents are connected, so value alignment there is a property of the whole system.
